# atmos-IAA plotting tutorial

Welcome to the tutorial! These materials are meant to supply important Python functions and instructions that will help people visualize the output of atmos-IAA, a coupled climate/photochemistry code that computes atmospheric models. You can read more about the original atmos code here: https://github.com/VirtualPlanetaryLaboratory/atmos

Within this directory there are these files/folders:

- Data: a directory containing the output of 27 atmospheric models and other datafiles necessary for plotting output.
- Plots: a directory showing PDFs of the plots that can be created with this tutorial
- README.md: the file you're reading now. Hope it is helpful!
- output_examples: contains examples of the output files that contain the most import atmos-IAA output
- read_atmos_IAA.py: the Python script containing all of the functions necessary to clean and extra data from the atmos-IAA output files
- test_read_atmos_IAA.py: the Python script containing the instructions and plotting tutorial for data extraction and data visualization of atmos-IAA output files

To get started on your data visualization journey, load up test_read_atmos_IAA.py on your favorite Python editor and get started by reading the instructions!

# IMPORTANT INFO:
Required software: Python 3.=+, numpy, matplotlib.pyplot
Make sure read_atmos_IAA.py is either in the same directory as test_read_atmos_IAA.py or somewhere that Python will look for packages.
